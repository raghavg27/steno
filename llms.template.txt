## How it works

- Paste the instruction layer into custom instructions, project instructions or a system prompt. The model writes clean text from the start.
- Or run the skills file on text you already have. It keeps every fact and number and only changes how the text sounds.
- It targets twelve families of AI writing tells, such as puffed up openers, three item lists, vague attribution and uniform rhythm.
